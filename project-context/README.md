# Contexto persistente del proyecto

Esta carpeta conserva decisiones, aprendizajes y trazabilidad para que futuras etapas no dependan del historial del chat.

- `history/`: bitácora cronológica de avances.
- `decisions/`: decisiones de producto y técnicas, con su fundamento.
- `skills/`: guías reutilizables que se creen específicamente para Due Sorelas.
- `agents/`: roles, prompts y convenciones de agentes que se definan para el proyecto.

No contiene secretos, tokens ni credenciales.
